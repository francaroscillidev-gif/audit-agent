# Security Policy

## Supported Versions

We release patches and security fixes for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability (Responsible Disclosure)

The security of **AuditAgent** and the smart contracts/applications it analyzes is our top priority. If you discover a security vulnerability or critical logic flaw in this project, please report it responsibly.

### Disclosure Process

1. **Do NOT open a public GitHub issue.**
2. Send an email to the lead maintainer:
   - **Contact:** Franca Roscilli
   - **Email:** [francaroscillidev@gmail.com](mailto:francaroscillidev@gmail.com)
   - **Subject Line:** `[SECURITY DISCLOSURE] AuditAgent - <Short Vulnerability Summary>`
3. Include the following details in your report:
   - Detailed description of the vulnerability
   - Affected component(s) or file(s)
   - Step-by-step reproduction instructions or Proof-of-Concept (PoC)
   - Potential impact (e.g. arbitrary code execution, false negative bypass)
   - Proposed fix or mitigation (if available)

### Response SLA

- **Acknowledgment:** Within 24-48 hours.
- **Triage & Assessment:** Within 3-5 business days.
- **Fix & Advisory Release:** A patched release will be coordinated and credited to the reporter in the release notes.

Thank you for helping keep the open-source security community safe!
